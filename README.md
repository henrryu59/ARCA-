# ARCA — Aprendizaje en Relaciones Con Amor

Sitio web de Henrry Urbina: acompañamiento psicoterapéutico, coaching y psicoespiritual para
personas y parejas. Presencial en Caracas y en línea.

## Qué hay aquí

Un sitio estático: solo HTML, CSS e imágenes. No necesita compilarse ni instalar nada.

| Archivo | Qué es |
|---|---|
| `index.html` | Inicio |
| `nosotros.html` | Nosotros |
| `servicios.html` | Servicios |
| `blog.html` | Índice del blog |
| `articulo-*.html` | Los artículos |
| `contacto.html` | Contacto y formulario |
| `styles.css` | Toda la apariencia del sitio |
| `logo.png`, `foto-*.jpg`, `portada-*` | Imágenes |

## Cómo se publica

Está pensado para Vercel: al conectar este repositorio, Vercel detecta un sitio estático y lo
publica sin configuración. Cada cambio que se guarde aquí se publica solo.

## Formulario de contacto

`contacto.html` envía a **Formspree**. Antes de que funcione hay que reemplazar
`TU_ID_DE_FORMSPREE` en el atributo `action` del formulario por el identificador real de la cuenta.
